# Documentation Review Notes

## 整合性確認

- READMEの設定場所を、現行の右上歯車ダイアログへ統一しました。
- README、AGENTS、コードの既定値は beam 1 / 15秒 / CPU 8 / 文脈300で一致します。
- キャッシュ場所とローカルモデル限定方針はコード、README、配布資料で一致します。
- 配布物からモデルとユーザーデータを除外する方針はspecとテストで固定されています。

## 既知の不足と推奨

- Flet画面の自動スクリーンショット/E2Eテストはなく、構造テストが中心です。
- 実音声によるCPU速度・精度ベンチマークはありません。
- 推論デバイス、WAV保存、辞書本文は現在キャッシュされません。仕様変更時はREADMEと
  `AppSettings` の双方を更新してください。
- OSごとの実デバイス互換性はfake backendテストだけでは完全に保証できません。
- `tests/test_gui.py` の一部は明示的な `SettingsStore` を注入せず、実行環境の
  ユーザーキャッシュに影響されます。テスト実行時は `XDG_CACHE_HOME` を隔離し、
  将来は全GUIテストへ一時ストアを注入することを推奨します。
- このワークスペースにはGit管理情報がないため、変更履歴ベースの要約は作成できません。
